SokoHub Marketplace — Official Documentation
============================================

This folder contains the standalone product documentation for the SokoHub
Uganda Classifieds Marketplace built with Next.js 16, React 19 and Tailwind CSS 4.

Open `documentation/index.html` directly in a browser.

No Next.js runtime, npm install, database, or local development server is
required to read the documentation.

Included assets:
- assets/css/documentation.css
- assets/js/documentation.js
- assets/images/screenshots/*.png placeholders
- assets/images/logo/logo.svg

Before publishing, replace the placeholder screenshots in
`assets/images/screenshots/` with real screenshots from your application.
